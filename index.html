          How it works

          1. Enter a profile. A username, @handle or any github.com link works.
          2. We fetch public data. From our own API first, with several public APIs as automatic backups if one is down.
          3. Your year becomes a city. Every day is a building, height and color show how much you shipped.
          4. Share. Link with a live preview, card, video, GIF, year in review, README card or a 3D print.

          FAQ

          Do I need to log in?

          No. Only public GitHub data is used. No accounts, no cookies, no tracking.

          Why don't my private contributions show?

          Private contributions only count if you enable “Include private contributions on my profile” in your GitHub settings. They then show up as numbers without details.

          The numbers look slightly off.

          Contribution data is cached for about an hour. Recent commits may take a moment to appear.

          What if a data source is down?

          Gridscape tries several sources one after another and remembers which ones failed for a few minutes. The footer shows where your data came from.

          How do I print my skyline?

          Download the STL and open it in any slicer (PrusaSlicer, Cura, Bambu Studio). No supports needed; scale it to fit your printer.

          Does it work on my phone?

          Yes. Use one finger to rotate, two to zoom. On older devices you can switch to the 2D view.
